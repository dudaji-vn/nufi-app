NuFi box

This box serves everything over HTTPS with its own certificate authority. Trust the certificate once, then use the links below.

Download the certificate (nufi-box-ca.crt)

Trust it

  1. Windows: double-click the file → Install Certificate → Local Machine → Place all certificates in the following store → Trusted Root Certification Authorities.
  2. macOS: double-click the file (opens Keychain Access) → find "NuFi box" or "Caddy Local Authority" under login → double-click → Trust → Always Trust.
  3. Ubuntu: sudo cp nufi-box-ca.crt /usr/local/share/ca-certificates/ && sudo update-ca-certificates; Chrome and Firefox also need it under Settings → Certificates → Authorities.
