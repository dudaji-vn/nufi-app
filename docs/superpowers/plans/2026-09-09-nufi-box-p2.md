# NuFi box P2 — "from home" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A member on an LTE hotspot installs the official Tailscale app, runs one file from `nufi-box invite`, and then uses the box as on the LAN: chat at `https://nufi.<base>:3080`, the department drive as `\\nufi\<dept>`, and a Studio routine that reads a file from that drive. The mechanism is proven in a local Docker lab that forces the DERP relay; the field test on a VPS is the first task of P3. Two P1 closers come first: a timed blank-Ubuntu install in a Lima VM, and the weekly demo video.

**Architecture:** `deploy/coordinator/` runs headscale with its embedded DERP and STUN behind Caddy. The box joins it as node `nufi` (a `tailscale` container with host networking on Linux; the native Tailscale app on macOS), gets a mesh IP and the MagicDNS name `nufi.<base>`, and Caddy adds that name and IP as SANs on the existing box CA. `nufi-box invite` asks the coordinator for a single-use pre-auth key and writes a per-OS join file (CA trust + `tailscale login` + drive mapping + open the chat URL). Samba binds the mesh IP too. Studio mounts the drives read-only so the four recipe flows can read department files.

**Tech Stack:** headscale `v0.29.3` (`ghcr.io/juanfont/headscale`), `tailscale/tailscale:v1.102.3`, Caddy 2.10 (already), Lima 2.2 for the Ubuntu VM, `registry:2` for a LAN image registry, bash 3.2 scripts, stdlib Python tests, the existing `deploy/platform/scenarios/{demo,studio}` machinery.

**Spec:** `docs/superpowers/specs/2026-09-09-nufi-box-p2-design.md` (approved 2026-09-09); parent spec `docs/2026-09-08-nufi-team-box-plan.md` §3 rows G–L, §4 P2.

## Global Constraints

- Every image pinned; never `:latest`. Every compose service: `restart: unless-stopped`, a healthcheck, explicit network.
- Shell scripts run under macOS `/bin/bash` 3.2; `set -euo pipefail` safe; no `timeout(1)` on macOS (use `curl --max-time`, `--retry`, or a loop).
- Tests are stdlib Python or pytest under `uv run --with pytest`; the platform ruff gate (`cd deploy/platform && uv run --with ruff==0.9.2 ruff check .`) must stay clean; `deploy/box/tests` and `deploy/coordinator/tests` run in `box-ci.yml`.
- Secrets never committed: coordinator API keys, pre-auth keys, headscale private keys live in `.env`/volumes; join files are written under `data/invites/` (gitignored) and named in the audit line the daemon logs.
- Commit messages in English ending with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>` and `Claude-Session: https://claude.ai/code/session_012hq1mtssdESTpVpHQFd2rL`. Branch `feat/box-p2` from `origin/main`.
- Names: coordinator `MESH_SERVER_URL` (e.g. `https://mesh.nufi.me`), MagicDNS `MESH_BASE_DOMAIN` (e.g. `box.nufi.me`; headscale requires it to differ from the server hostname), the box node is named `${BOX_NAME}` (default `nufi`), tags `tag:box` and `tag:member`, headscale user `box`. Box env keys: `MESH_SERVER_URL MESH_API_KEY MESH_AUTH_KEY BOX_MESH_HOST BOX_MESH_IP NUFI_REGISTRY`.
- Ports unchanged: 80/3080/3001/3002/7860/4000/445 on the box; coordinator 443/tcp (control + DERP), 3478/udp (STUN).
- The Mac box in `.claude/worktrees/box-p1/deploy/box` stays running; P2 work happens in a new worktree. Do not touch Docker Desktop settings or other stacks.
