---
title: Chat with a document
description: Upload a PDF or report and ask questions, get summaries, and translate it — all in one conversation.
---

Have a long PDF, contract, or report you don't want to read end to end?
Upload it and ask NUFI about it. You'll get answers grounded in the
document — summaries, specific facts, and translations — without pasting
anything by hand.

## What you'll need

- A file to work with — PDF, Word, plain text, or Markdown.
- Any recent model. For a **scanned** document or a photo of text, pick a
  vision-capable model (see [Models](/docs/end-user/models-and-presets#pick-a-model)).

## Steps

<Steps>
<Step>Start a **new chat**.</Step>
<Step>
Click the **paperclip** (Attach File) at the bottom-left of the message box —
or just **drag the file** onto the conversation. Choose **Upload to Provider**
for rich documents, or **Upload as Text** to pull the text into your prompt.

![The attach menu with Upload to Provider and Upload as Text](/screenshots/chat-attach-menu.png)
</Step>
<Step>
Ask your first question, for example:

> Summarise the key findings of this report in 5 bullets.
</Step>
<Step>
Keep going in the same chat — the file stays in context:

> What does section 3 say about pricing?

> Translate the conclusion into Vietnamese.
</Step>
<Step>
Comparing **several** files at once? Open the **Tools** menu (the sliders icon)
and turn on **File Search** so the AI can look across everything you've
uploaded.

![The Tools menu with File Search](/screenshots/chat-tools-menu.png)
</Step>
</Steps>

## What you get

Answers that quote the document instead of guessing — for example:

> **Key findings**
> - Revenue grew 18% year over year, driven by the EU region.
> - Support costs fell after the March automation rollout.
> - …

You can follow up, translate, or ask for the exact wording of any section.

## Make it better

- **One document per chat** keeps answers focused. Start a fresh chat for a
  different file.
- **Use File Search** when you want to compare or search across many uploaded
  files at once.
- **Scans and photos** need a vision model — if the AI can't "see" the text,
  switch models.
- Want a document that stays available in **every** chat and can be **shared
  with your team**? Build a knowledge agent instead — see the guide below.
