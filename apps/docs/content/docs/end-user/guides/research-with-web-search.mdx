---
title: Research a topic with web search
description: Get up-to-date, source-cited answers by letting an agent search the live web, then drill into the sources.
---

A model answers from its training data, which stops at a date. With web
search on, an agent looks things up first and answers with citations you
can open.

<Callout type="warn">
Web Search is not switched on for `chat.nufi.me` at the moment. This
guide is for deployments that have it.
</Callout>

## What you will need

- Web search connected by your organisation.
- [Advanced mode](/docs/end-user/advanced-mode), and a conversation with
  a plain model, where the **Tools** menu lists **Web Search**. An agent
  with the capability enabled works too — see
  [Agents](/docs/end-user/agents).

## Steps

<Steps>
<Step>Start a new chat and pick a model from the model picker.</Step>
<Step>
Open the **Tools** menu — the sliders icon beside the paperclip — and turn
on **Web Search**. It stays on for the rest of the conversation.
</Step>
<Step>
Ask something that needs current information:

> What changed in the EU AI Act timeline this year, and when do the main
> obligations start?
</Step>
<Step>
The model turns the question into searches, reads the top results, and
answers with numbered citations that link back to each source.
</Step>
<Step>
Narrow and verify:

> Focus on obligations for small companies.

> Read source 2 more carefully. What does it say about deadlines?
</Step>
<Step>
Optionally attach one of your own files and ask for a comparison with
what it found.
</Step>
</Steps>

## Make it better

- **Ask for sources** — *"cite each claim"* — and be specific about
  scope and dates.
- **Cross-check** anything important before you rely on it.
- **Privacy:** what the model looks up leaves NUFI as a search query.
  Turn search off for confidential prompts. Text that comes back from a
  web page is treated as untrusted by the security checks, so a page
  cannot quietly redirect the model.
