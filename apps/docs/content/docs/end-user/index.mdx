The NUFI app is your AI workspace — a private, secure space where you
can talk to powerful AI models, build assistants, search the web, work
with files, and let the AI write code for you.

You will use two web apps:

- **The app** at `chat.nufi.me` — your day-to-day conversations,
  agents, files, presets.
- **The console** at `console.nufi.me` — only needed if you want to
  call NUFI from your own code or scripts. Sign in once at the app;
  the console reads the same session.
