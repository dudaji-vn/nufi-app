## Upload a file

Click the **paperclip** icon next to the message box, or just **drag
a file** onto the conversation. NUFI handles the file based on what
it is:

- **Images** — sent directly to the model (for vision-capable
  models). Ask the model anything about the image.
- **Documents** (PDF, Markdown, plain text, code files) — NUFI reads
  the document, finds the relevant parts, and includes them in your
  prompt automatically. You do not have to paste the contents.

You can attach multiple files in one message.

## What works out of the box

| Type     | Examples                              |
|----------|---------------------------------------|
| Images   | PNG, JPEG, WebP, GIF                  |
| Docs     | PDF, plain text, Markdown             |
| Code     | `.py`, `.ts`, `.go`, `.md`, …         |

Limits per message:

| Limit          | Default |
|----------------|---------|
| Files / msg    | 5       |
| Per file size  | 20 MB   |
| Total          | 50 MB   |

Need more? Ask your admin to raise the cap for your team.

## Talk to a document

Upload a PDF, then ask questions about it:

> Summarise the main findings of this report in 5 bullets.

> What does section 3.2 say about pricing?

> Translate the conclusion into Vietnamese.

NUFI extracts the relevant pages, feeds them to the model, and
returns an answer with citations to the source.

## Look at an image

Upload an image, then ask:

> What is in this photo?

> Read the text in this screenshot and turn it into a table.

> Suggest three improvements to this UI design.

You need a **vision-capable** model — look for the 👁️ badge in the
model dropdown.

## Generate images from prompts

Type `/image` at the start of the message box, then describe what you
want:

```
/image a watercolour fox reading a book in a cosy library,
       soft pastel colours, dawn lighting
```

The image lands in the conversation and is saved to your account so
you can re-download it later. To make variations, hover the image
and click **Variations** or just describe the change in your next
message.

## Edit an image

Upload an image, then describe the change in plain English:

> Make the sky purple and add a moon.

> Remove the watermark in the bottom-right.

> Add a smiling cartoon dog next to the desk.

You keep both versions — the original is preserved next to the edit.

## Storage and privacy

Files you upload are saved to your account and visible only to you
(plus anyone you explicitly share a conversation with). Deleting a
conversation also deletes its files.

To delete a single file, hover it in the conversation → **·  ·  · ** →
**Delete**.

## Errors you might see

- **"File too large"** — your file is over the per-file cap. Compress
  or split it.
- **"Out of budget"** — image generation is more expensive than text.
  Check your usage in the [console](/docs/end-user/api-keys).
- **"Please slow down"** — too many requests in a short window. Wait
  a few seconds.
