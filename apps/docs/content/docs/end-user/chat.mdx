NUFI Chat works like ChatGPT — type, press Enter, get a streaming
reply. A handful of extras are worth knowing.

## Send a message

Type into the box at the bottom and press **Enter**. **Shift+Enter**
for a newline. The reply streams in word by word.

While it is streaming you can:

- Hit **Stop** to cancel mid-response.
- Hit **Regenerate** to ask for a different answer to the same prompt.

## Edit and resubmit

Hover any message you sent and click the **pencil** icon. Change the
text, click **Save**. The conversation **branches**: the original
reply stays on one branch, the new edited prompt produces a new
reply on another. Switch between branches with the arrows under the
assistant's reply.

This is how you ask "what if I phrase it differently?" without losing
the original answer.

## Branching and forking

- **Branching** happens automatically when you edit a message.
- **Forking** is explicit — right-click any message → **Fork from
  here**. A fresh conversation opens, seeded with everything up to
  that message. Great for exploring a tangent without polluting the
  main thread.

## Bookmarks

Star any conversation to add it to **Bookmarks** (left sidebar). Use
this for the small set of conversations you reference often — a
project, a recurring task, a useful prompt.

## Multi-conversation mode

The **+** button next to the model picker opens a second conversation
**side-by-side**. Useful for:

- A/B-testing two prompts.
- Comparing how two models answer the same question.
- Drafting in one pane while reading reference material in the other.

## Temporary chat

The **clock** icon next to the message box starts an **ephemeral**
conversation. Nothing is saved — once you close the tab, the
conversation is gone.

Use temporary chat for:

- Sensitive questions you do not want recorded.
- One-off experiments.
- Sharing your screen without exposing past conversations.

## Search

The **magnifying glass** in the sidebar searches every conversation
you have. Results jump straight to the matching message — handy when
you remember an answer but not which chat it came from.

## Export and share

Each conversation has a **·  ·  · ** menu in the top-right:

- **Export** → JSON, Markdown, or screenshot (PNG).
- **Share** → public link or share with specific teammates.
- **Import** → bring back a conversation from a previous export.

## Keyboard shortcuts

| Shortcut          | Action                                  |
|-------------------|-----------------------------------------|
| **Enter**         | Send the message                        |
| **Shift+Enter**   | New line in the message box             |
| **Ctrl/⌘ + K**    | Universal jump bar — find anything      |
| **Ctrl/⌘ + /**    | Toggle the side panel                   |
| **/** (in box)    | Insert a saved prompt or run a command  |

## Limits

NUFI is shared across your organisation, so each account has limits:

- **Speed limit** — how many messages per minute. If you go very
  fast, the chat shows a "please slow down" notice. Wait a few
  seconds.
- **Monthly budget** — how much your account can spend on AI per
  cycle. If you hit it, you will see "Budget reached". Ask your
  admin to increase it if you need more.

Your current usage is visible in the [console](/docs/end-user/api-keys).
