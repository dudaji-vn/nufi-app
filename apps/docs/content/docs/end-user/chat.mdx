The NUFI app works like ChatGPT — type a question, press **Enter**,
and the answer streams back word by word. This page walks you through
it click by click.

![A conversation in the NUFI app, with the answer toolbar under the reply](/screenshots/chat-conversation.png)

## Send your first message

<Steps>
<Step>Open `chat.nufi.me`. You land on a **New chat** with an empty
message box at the bottom that says **"Message Nufi"**.</Step>
<Step>Click the box and type your question, for example
*"In one friendly sentence, what can you help me with?"*</Step>
<Step>Press **Enter** to send. (Use **Shift + Enter** if you want a
new line instead of sending.)</Step>
<Step>The reply streams in under **Nufi**. Wait for it to finish —
that's it, you're chatting.</Step>
</Steps>

While a reply is still streaming you can click **Stop** to cancel it,
or **Regenerate** afterwards to ask for a different answer to the same
question.

## The answer toolbar

Hover (or look just under) any reply from Nufi and a small row of
icons appears — left to right:

| Icon | What it does |
|------|--------------|
| 🔊 Speaker | Read the reply aloud — see [Speech](/docs/end-user/speech) |
| ⧉ Copy | Copy the reply to your clipboard |
| ✏️ Pencil | Edit your message and try again (see below) |
| ⑂ Branch | Fork a new conversation from this point |
| 👍 / 👎 | Tell your admins whether the answer was good |
| ⟳ Regenerate | Ask for a fresh answer |

## Edit and try again

Click the **pencil** on a message *you* sent, change the wording, and
click **Save**. The conversation **branches**: your original reply is
kept on one branch, the edited prompt creates a new reply on another.
Use the small arrows under the reply to switch between them.

This is how you ask *"what if I phrase it differently?"* without
losing the original answer.

## Start a new chat

Click **New chat** (top of the left sidebar) any time you want a
clean, separate conversation. Past chats are listed below it, grouped
by **Previous 7 days**, **Previous 30 days**, and so on. Click any one
to reopen it.

## Two chats side by side

The **Add multi-conversation** button in the top bar (next to the
model name) opens a second conversation **beside** the first. Handy
for:

- Comparing how two models answer the same question.
- Drafting in one pane while reading reference material in the other.

## Temporary chat

The **Temporary Chat** button in the top bar starts an **ephemeral**
conversation — nothing is saved. Close the tab and it's gone. Use it
for one-off or sensitive questions you don't want kept in your
history.

## Find an old answer

Click **Search messages** at the top of the sidebar and type a word
you remember. Results jump straight to the matching message — useful
when you recall an answer but not which chat it came from.

## Bookmarks

Star a conversation to add it to **Bookmarks** in the left sidebar.
Keep the handful of chats you return to often within easy reach.

## Keyboard shortcuts

| Shortcut          | Action                                  |
|-------------------|-----------------------------------------|
| **Enter**         | Send the message                        |
| **Shift + Enter** | New line in the message box             |
| **Ctrl/⌘ + K**    | Jump bar — find anything                |
| **/** (in box)    | Insert a saved prompt or run a command  |

## Limits

NUFI is shared across your organisation, so each account has limits:

- **Speed limit** — how many messages per minute. If you go very
  fast, the app shows a "please slow down" notice. Wait a few
  seconds.
- **Monthly budget** — how much your account can spend on AI per
  cycle. If you hit it, you will see "Budget reached". Ask your
  admin to increase it if you need more.

Your current usage is visible in the [console](/docs/end-user/api-keys).
