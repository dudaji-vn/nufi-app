title: Speech
description: Talk to the chat hands-free and have replies read aloud.

NUFI can transcribe your voice into a message and read replies back
out loud — useful when your hands are busy, on the move, or if
typing is uncomfortable.

## Voice in (talk to the chat)

The **microphone** icon next to the message box records your voice.
Tap once to start, tap again to stop. The text appears in the
message box; edit if needed, then send.

If the icon is missing, your organisation has not connected a
voice-to-text engine. Ask your admin.

## Voice out (read replies aloud)

Hover any reply from the AI and click the **🔊** icon. The reply is
read aloud as it streams in.

## Hands-free mode

Open **Settings → Speech** to enable:

- **Auto-send** — when you stop talking, the message sends
  automatically. No tap needed.
- **Auto-play** — every reply is read aloud as it arrives.

Combine both for a true hands-free experience — you talk, NUFI
answers, you talk again. Great for car / walking / cooking.

## Languages

Voice input automatically detects the language you speak. Voice
output uses the language NUFI is set to (Settings → General →
Language).

Most major languages work out of the box, including English,
Vietnamese, Chinese, Japanese, Korean, and most European languages.

## A note on privacy

Voice input and output send audio out of your deployment to a speech
provider. If you have something sensitive to say, type it instead —
or turn auto-send off so you can review the text before pressing
send.

## Common issues

- **Microphone permission denied** — your browser blocks NUFI from
  using the mic. Click the lock icon in the address bar and allow
  microphone access.
- **Audio sounds robotic** — that is the speech engine. Some
  organisations connect a higher-quality engine; ask your admin
  about ElevenLabs.
- **Voice output cuts off** — your network dropped briefly. NUFI
  resumes from where it stopped on the next reply.
