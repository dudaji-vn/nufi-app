title: Web search
description: Let an agent look things up on the live web before it answers, where your organisation has enabled it.
---

A model answers from what it learned during training, which stops at a
date and knows nothing about your situation. **Web Search** lets the
model look things up live before replying.

> **Guide:** [Research a topic with web search](/docs/end-user/guides/research-with-web-search).

<Callout type="warn">
**Web Search is not switched on for `chat.nufi.me` at the moment.** The
Tools menu there offers File Search only. This page describes the
feature for deployments that have it, and for the day yours does.
</Callout>

## What it needs

1. Your organisation has connected a search provider. When it has not,
   **Web Search** is simply absent.
2. You are in [Advanced mode](/docs/end-user/advanced-mode).
3. Either a plain model, where the **Tools** menu beside the paperclip
   lists it, or an agent with **Web Search** among its capabilities —
   see [Agents](/docs/end-user/agents).

## Turn it on

<Steps>
<Step>In a conversation with a plain model, open the **Tools** menu — the
sliders icon beside the paperclip.</Step>
<Step>Click **Web Search**. The gear beside it holds provider options,
if your deployment exposes any.</Step>
<Step>Ask as normal. Search stays on for the rest of the conversation;
open the menu again to turn it off.</Step>
</Steps>

## What happens when it is on

The model turns your question into one or more searches, reads the top
results, and writes its answer from them with numbered citations that
link back to each page.

Search shines for anything newer than the model's training — news,
prices, versions, live figures — and for answers you want to be able to
verify. It adds nothing to brainstorming, creative writing, or a
question whose source material you already pasted in.

## Tips

- **Be specific.** *"Compare the 2025 camera reviews of phone A and
  phone B"* beats *"which phone is better?"*
- **Ask for sources** — *"cite each claim"* — and drill in: *"read source
  2 again; what does it say about deadlines?"*
- **Cross-check** anything you will act on.

## Privacy

Whatever the model needs to look up becomes a search query that leaves
NUFI for the search provider. Turn search off for confidential prompts.
The security checks described in
[How your data is protected](/docs/end-user/security) still run on what
comes back: text inside a fetched page is treated as untrusted.

## If Web Search is not in the menu

In order of likelihood: your organisation has not connected a provider
(the case on `chat.nufi.me` today); you are in Basic mode; you are
chatting with an agent that does not have the capability enabled. The
last two you can fix yourself.
