NUFI is an AI app for teams — a secure workspace like Claude, ChatGPT or
Gemini, scoped to your organisation.

The sidebar lists every section of this manual, in reading order. This
page answers the question that comes before that: **where do I start?**

## Start from what you want to do

| I want to… | Go to |
|---|---|
| Understand what NUFI is | [Overview](/docs/overview) |
| Use the app for the first time | [Sign in](/docs/end-user/sign-in) |
| Ask questions about my documents | [Chat with a document](/docs/end-user/guides/chat-with-a-document) |
| Build a pipeline I can call from code | [NUFI Studio](/docs/studio/getting-started) |
| Put a team of agents to work | [NUFI Works](/docs/works/getting-started) |
| Give my team access and set budgets | [Administer](/docs/admin) |
| Stand up a production instance | [Deploy & operate](/docs/deployment) |
| Run the stack on my laptop | [Develop](/docs/developer) |
| Call NUFI from my own code | [API keys](/docs/end-user/api-keys) |
| Look up a port or a variable | [Reference](/docs/reference) |

## The two agent products

They are separate apps, both reached from `agents.nufi.me` with the NUFI
account you already have.

<Cards>
  <Card icon={<Workflow />} title="NUFI Studio" href="/docs/studio">
    A canvas. Wire a model, your documents and a tool into a flow, run it,
    and publish it as an endpoint.
  </Card>
  <Card icon={<GroupIcon />} title="NUFI Works" href="/docs/works">
    An operations app. Give a team of agents a goal, approve what matters,
    and watch the spend.
  </Card>
</Cards>

## If you are new

Read [Overview](/docs/overview) first — it is short, and it explains the
pieces the rest of the manual assumes you know. Then
[Sign in](/docs/end-user/sign-in) and use the app for ten minutes. Most
of the rest will make sense after that.
