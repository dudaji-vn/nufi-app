NUFI is an AI chat platform for teams — a conversational workspace
like Claude, ChatGPT, or Gemini, scoped to your organisation. This
manual is filtered by **what you are trying to do** so you only see
the pages that matter to you.

Pick a lane below. You can switch any time from the sidebar tabs.

<Cards>
  <Card title="📖 Overview" href="/docs/overview">
    What NUFI is and how it works. Read this first if you are new.
  </Card>
  <Card title="💬 End user" href="/docs/end-user">
    You are using the chat. Sign in, pick a model, work with agents,
    files, presets, web search. Manage API keys in the console.
  </Card>
  <Card title="🛠️ Admin" href="/docs/admin">
    You manage NUFI for your organisation. Configure features,
    users, roles, groups, scoped overrides, and watch usage.
  </Card>
  <Card title="🧑‍💻 Developer" href="/docs/developer">

    dev setup, model registration, release flow.
  </Card>
  <Card title="🚀 DevOps" href="/docs/deployment">
    You are running NUFI in production. Infra, environment, SSO,
    monitoring, backups, troubleshooting.
  </Card>
  <Card title="📚 Reference" href="/docs/reference">
    Flat lookup tables — every port, environment variable, glossary.
  </Card>
