---
title: Users and membership
description: Where accounts come from, and how you give people roles and groups.
---

People get a NUFI account by signing in to the app: self-registration
when it is open, or your identity provider. Registration is switched on
the **System** tab of [Configuration](/docs/admin/configuration). The
admin panel has no user-creation screen in the shipped build (the page
exists in the code and is disabled), so as an admin you decide what each
person can do by putting them into **roles** and **groups** on
[Access](/docs/admin/roles-and-groups).

## Give someone admin powers

<Steps>
<Step>Make sure the person has signed in to the app at least once, so the
account exists.</Step>
<Step>Open **Access → Roles** and click the role: `ADMIN`, or a sub-admin
role of your own that holds `access:admin`.</Step>
<Step>On the **Members** tab, add them.</Step>
<Step>Save. They can open the admin panel on their next request.</Step>
</Steps>

![The Members tab lives inside each role on the Access page](/screenshots/admin-role-detail.png)

To take the powers away, remove them from the role's **Members**. With no
admin role left, they are an ordinary user of the app again.

## Give a set of people different features or limits

<Steps>
<Step>On **Access → Groups**, create a group and add the members.</Step>
<Step>In [Configuration](/docs/admin/configuration), create a profile for
the group and set the model, feature or limit.</Step>
</Steps>

[Configuration profiles](/docs/admin/scoped-overrides) explains how the
values resolve when a person is in several groups.

## Budgets, keys and usage

Budgets, rate limits and API keys live in the gateway, not here. Each
member manages their own keys in [NUFI Console](/docs/end-user/api-keys),
where they also see their spend; an admin sees everything in the
gateway's own UI, [Gateway admin](/docs/admin/litellm). The app's own
traffic runs on one shared gateway key, so a person's chat usage shows up
in Langfuse under their id but is not capped per person by the gateway.

## Removing a person

Delete the account in the app's own settings, or disable it at your
identity provider; the admin panel does not delete accounts. Their
conversations and files go with the account.
