---
title: Choose your path
description: Pick the smallest install that matches what you actually need.
---

There are three reasonable starting points. Pick whichever fits.

## A. Run NUFI locally (developer / DevOps)

You want the full platform — chat, console, gateway, observability,
monitoring — on your laptop, talking to a local model server or a
cloud AI provider.

→ Read [Prerequisites](/docs/getting-started/prerequisites) then
[Quick start](/docs/getting-started/quick-start).

## B. Stand up a single chat product (small deployment)

You already have an AI gateway (your own, OpenRouter, raw OpenAI)
and just want NUFI's chat experience in front of it. You do not
need the developer console, observability, or safety filters.

→ Use the **nufi-chat** standalone deployment. See
[Developer → nufi-chat](/docs/developer/nufi-chat).

## C. Develop against an existing NUFI install

NUFI is already running somewhere and you want to develop a
specific component locally — admin panel, console, chat.

→ Go straight to [Developer](/docs/developer) and pick the
component.

## What you do not need to do

If you only want to **use** NUFI, you do not need any of this. Ask
your admin for the chat URL, see [End user](/docs/end-user).

If you only want to **administer** an existing deployment, see the
[Admin](/docs/admin) section.
