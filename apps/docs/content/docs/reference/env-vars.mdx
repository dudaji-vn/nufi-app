(`VITE_LIBRECHAT_URL`), `LITELLM_URL` (`VITE_LITELLM_URL`),
`VITE_WORKS_URL`.

## How the secrets are generated

`scripts/bootstrap.sh` in `deploy/platform`: `openssl rand -hex 32` for
`LITELLM_MASTER_KEY`, `LITELLM_SALT_KEY`, `JWT_SECRET`,
`JWT_REFRESH_SECRET`, `CREDS_KEY`, `LANGFUSE_ENCRYPTION_KEY`; `-hex 16` for
`POSTGRES_PASSWORD`, `CREDS_IV`, `MONGO_INITDB_ROOT_PASSWORD`,
`LANGFUSE_PUBLIC_KEY`, `LANGFUSE_SECRET_KEY`, `CLICKHOUSE_PASSWORD`,
`MINIO_ROOT_PASSWORD`, `E2E_USER_PASSWORD`; `-base64 32` for
`LANGFUSE_NEXTAUTH_SECRET`, `LANGFUSE_SALT`; `-hex 12` for
`LANGFUSE_INIT_USER_PASSWORD`, `GRAFANA_ADMIN_PASSWORD`. Only values that
still end in `replace-me` are filled; a blank stays blank.
