## The compose stack (`deploy/platform`, project `npuops`)

| Host port | Service | Container port | What |
|---|---|---|---|
| 3080 | `librechat` | 3080 | the NUFI app |
| 3001 | `console` | 3000 | NUFI Console |
| 3000 | `langfuse-web` | 3000 | Langfuse |
| 3030 | `grafana` | 3000 | Grafana (3000 is taken by Langfuse) |
| 4000 | `litellm-proxy` | 4000 | the gateway, and its admin UI at `/ui` |
| 9090 | `prometheus` | 9090 | Prometheus, admin only |
| 9093 | `alertmanager` | 9093 | Alertmanager, admin only |

No host port: `postgres` (5432), `redis` (6379), `clickhouse` (8123,
9000), `minio` (9000), `minio-init`, `langfuse-worker`, `mongodb` (27017),
`postgres-exporter` (9187), `redis-exporter` (9121), `presidio-analyzer`
(3000), `presidio-anonymizer` (3000), `nufi-scanner` (8000), and
`e2e-test` (profile `e2e`).

## Dev servers

| App | Command | Port |
|---|---|---|
| the NUFI app, API | `npm run backend:dev` | 3080, or `PORT` |
| the NUFI app, client | `npm run frontend:dev` | 3090, proxying `/api` to `BACKEND_PORT` |
| NUFI Console, API | `bun run dev` | 3000, or `PORT`; 3002 in the guide, since 3000 is Langfuse |
| NUFI Console, client | same | 5173, proxying to `SERVER_PORT` |
| NUFI Admin Panel | `bun run dev -- --port <n>` | 3000 by default; 3003 in the guide |
| NUFI Studio, API | `langflow run --backend-only` | 7860, or `--port` |
| NUFI Studio, client | `VITE_PORT=<n> npm start` | 3000 by default, which is Langfuse; 3005 in the guide |
| NUFI Works, API | `pnpm run dev:server` | 3100 |
| this manual | `bun run dev` | 3000 |

With the compose stack up, 3000, 3001, 3030, 3080, 4000, 9090 and 9093
are taken. The guides in [Develop](/docs/developer) pick ports that do
not collide; `lsof -iTCP -sTCP:LISTEN -P -n | grep <port>` says who holds
one. Two TanStack apps (the console and the admin panel) also share a
devtools port, 42069, so only one of their dev servers runs at a time.
