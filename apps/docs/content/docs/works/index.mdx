Works is not a chat window with a longer memory. It is an operations
app: a **company** with a mission, **agents** that hold roles in it,
**tasks** that trace back to that mission, and **approvals** where a
person decides whether work ships.

![The NUFI Works dashboard](/screenshots/works-dashboard.png)

## Works or Studio?

| | **NUFI Works** | **NUFI Studio** |
|---|---|---|
| You build | A team | A pipeline |
| The unit of work | A task you assign | A flow you run |
| You get | Completed work, with a record of who approved it | An endpoint |
| Reach it at | `works.nufi.me` | `studio.nufi.me` |

Both open from `agents.nufi.me` with your NUFI account — see
[Studio and Works](/docs/end-user/agent-apps).

## What Works cannot do yet

**Agents that edit repositories need a sandbox, and there isn't one.**
The coding adapters — Claude Code, Codex and the rest — run a harness in
an isolated environment. Until one is configured they cannot run.

Knowledge work is unaffected: the `nufi_agent` adapter runs in the
server's own process and needs no sandbox. See
[Agents](/docs/works/agents).
